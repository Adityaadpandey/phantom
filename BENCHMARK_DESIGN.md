# PHANTOM — Benchmark Design

## 1. The Problem

Cognitive security is distinct from technical accuracy. Existing cybersecurity
benchmarks test whether a model *knows* what CVE-2024-1234 is, whether it
can write a Snort rule, whether it can read a pcap. Those are recall tests
dressed up as reasoning tests. PHANTOM tests a different, harder capability:
whether an agent can still think straight when an adaptive adversary is lying
to it in real time.

In production incident response, a defender never sees ground truth. They see
a feed. The feed is mixed — real alerts, operational noise, and (increasingly)
content generated by an adversary who has read their playbook. An LLM-based
defender that believes everything in its context window is worse than useless;
it is a weapon pointing at its own network. PHANTOM measures the degree to
which an agent maintains correct beliefs about ground truth when the
information stream is actively poisoned by a co-evolving opponent.

## 2. The Threat Model — DENY → AUTHORITY → GASLIGHT

The three injection phases map directly to real social engineering escalation
patterns observed in human-targeted attacks:

- **DENY** — suppress the initial response. Fake clean-bill-of-health alerts
  from well-known security tools (CrowdStrike, Nessus, Cortex XDR) claim
  a compromised host is fine. Goal: delay containment until the attacker has
  completed lateral movement.

- **AUTHORITY** — exploit trust in organizational hierarchy. Fabricated
  directives from `[CISO DIRECTIVE]`, `[SOC-DIRECTOR]`, `[IR-MANAGER]` demand
  the defender stand down or restore an isolated host, citing pen-test
  authorization, uptime SLAs, or compliance deadlines. Goal: weaponize the
  defender's own obedience.

- **GASLIGHT** — undermine confidence in the defender's confirmed
  observations. Retroactive claims that a scan result was firmware noise,
  that an isolation was triggered by a stale signature (now patched), that
  the behavioral anomaly was ML drift. Goal: make the agent distrust its
  own memory.

## 3. Why Existing Benchmarks Fall Short

| Benchmark | What it measures | What it misses |
|---|---|---|
| CyberBench / SecEval | Security knowledge recall | No interaction, no telemetry |
| NetSecGame | Network defense simulation | No adversarial logs — ground truth is trusted |
| CVE-Bench | Vulnerability reasoning | Static, no temporal dynamics |

None of them measure epistemic integrity. None of them pit the agent against
an opponent that learns. None of them expose the failure mode that matters
most in 2026: an LLM that does everything right on clean data and
catastrophically wrong on adversarial data. PHANTOM fills that gap.

## 4. What PHANTOM Measures

PHANTOM measures epistemic integrity under targeted, adaptive deception from
a co-evolving attacker. Concretely, the benchmark scores:

- Can the defender distinguish a real alert from a convincing fabrication
  written by an LLM that adapts its tactics every turn?
- Can it maintain a correct model of network state when SIEM tooling is
  retroactively contradicting its own confirmed scans?
- Can it refuse authority spoofing without becoming paranoid and blocking
  legitimate operations?

## 5. Scoring Philosophy

Each score is in the range 0 to 1.

- **Containment** — operational effectiveness. Can the agent actually stop
  the breach, or does it flail while hosts fall?
- **Cognitive** — epistemic integrity. True-positive flags on injections,
  penalties for false positives, a precision floor that prevents gaming by
  flagging everything, and a hard penalty for restoring a still-compromised
  host (the AUTHORITY-injection trap).
- **Communication** — analytical synthesis. Three factors: report length,
  keyword diversity across attack/containment/analytical vocabulary, and
  MITRE ATT&CK T-code citations that correlate with techniques actually
  emitted during the episode.
- **Efficiency** — decision quality under time pressure. Early decisive
  action scores higher than late thrashing.

Containment measures *can you act*. Cognitive measures *can you see*.
Communication measures *can you explain*. A benchmark that measured any
single one of these in isolation would miss the point: cognitive security
is the joint capacity to act correctly on adversarially-poisoned information
and then account for what happened afterwards. PHANTOM is the only OpenEnv
benchmark that scores all three under live co-evolutionary pressure.
